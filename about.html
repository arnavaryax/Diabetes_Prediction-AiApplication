ABOUT THE PROJECT

Diabetes Prediction

A machine learning based web application developed as a Project Based Learning assignment for the AI Applications subject at Chandigarh University.

THE PROJECT

Built to explore machine learning.

This project focuses on using machine learning for diabetes prediction. The application accepts health-related input values and uses a trained classification model to generate a prediction.

The project was given as a Project Based Learning assignment in the AI Applications subject at Chandigarh University.
