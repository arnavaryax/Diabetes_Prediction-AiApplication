HOW IT WORKS

From data to prediction.

A simple machine learning workflow that takes health-related inputs and produces a diabetes prediction through a trained classification model.

DATASET

What the model learns from.

PIMA INDIANS DIABETES DATASET

A classification problem.

The project uses the PIMA Indians Diabetes Dataset to train and evaluate the prediction models.

768 Records
8 Input Features
2 Classes
614 / 154 Train / Test

MODEL EVALUATION

Choosing the better model.

The models were evaluated using Accuracy and Recall. Recall was used as the selection criterion for the final model.

MODEL ACCURACY RECALL
Logistic Regression 70.78% 55.56%
Random Forest 87.01% 79.63%
Random Forest was selected based on the higher Recall.

APPLICATION FLOW

Frontend to model.

The website collects the input values and sends them to a Flask API. The API passes the values to the trained model and returns the prediction and probability to the frontend.
